02 — start ↗

Pierwszy eksperyment
w kilku linijkach.

01 / 03
example.py
from tota import Layer, Network

training_data = [
    ([1], 0), ([2], 0),
    ([6], 1), ([8], 1),
]

network = Network([Layer(5, 1), Layer(1, 5)])
print(network.learn(training_data, 0.01, 5000))
print(network.predict([7]))  # 1

03 — instrukcja ↗

Od danych
do pierwszej predykcji.

01Przygotuj dane✓

Każdy element to para: wektor wejściowy i oczekiwany cel. Dla prostego rozpoznawania użyj celu 0 lub 1.

dane = [
    ([1, 2], 0),
    ([6, 7], 1),
]
02Dobierz warstwy✓

Liczba wejść następnej warstwy musi odpowiadać liczbie neuronów warstwy poprzedniej.

Network([
    Layer(8, 2),
    Layer(1, 8),
])
03Uruchom uczenie✓

learning_rate określa wielkość kroku, a epochs — liczbę powtórzeń uczenia.

network.learn(
    dane, 0.01, 5000,
    show_progress=False,
)
04Oceń wynik✓

Po treningu przetestuj kilka znanych i nowych przykładów. predict zwraca klasę 0 albo 1.

for x, cel in dane:
    print(cel, network.predict(x))
04 — API ↗

Trzy elementy,
jedna działająca sieć.

Kliknij element, aby przejść do jego osobnego opisu i zobaczyć, za co odpowiada w kodzie.

01

Neuron ↗

Najmniejsza jednostka: wagi, bias i funkcja aktywacji.

Neuron(weight, bias, activation) 02

Layer ↗

Warstwa łączy wiele neuronów i przetwarza wektor wejściowy.

Layer(ilosc_neuronów, ilosc_wejsc) 03

Network ↗

Kontener warstw, który udostępnia uczenie i predykcję.

Network([layer, ...])

API 01

Neuron

Pojedynczy neuron liczy sumę ważoną wejść, dodaje bias i przepuszcza wynik przez aktywację.

neuron.forward(x)
  • weight — wektor wag wejściowych
  • bias — dodatkowe przesunięcie
  • activation — nazwa funkcji, domyślnie sigmoid
  • learn(...) — proste uczenie neuronu

API 02

Layer

Warstwa tworzy określoną liczbę neuronów i przekazuje ich wyniki dalej jako listę wartości.

Layer(3, 2, activation="relu")
  • pierwszy argument: liczba neuronów
  • drugi argument: liczba wejść
  • forward(x) — oblicza wyjście warstwy
  • każdy neuron w warstwie używa tej samej aktywacji

API 03

Network

Sieć łączy warstwy w kolejności podanej w konstruktorze i prowadzi uczenie metodą SGD.

network.learn(dane, 0.01, 5000)
  • forward(x) — przejście przez wszystkie warstwy
  • learn(...) — uczy parametry na danych
  • predict(x) — zwraca klasę 0/1
  • predict_ReLU(x) — zwraca wynik po ReLU
05 — transformer BETA ↗

Tekstowe modele
od tokena do tekstu.

Eksperymentalne API

Wydanie 1.0.1 aktualizuje dokumentację biblioteki. Funkcje Transformera opisane poniżej pozostają eksperymentalne i nadal mają status BETA; ich API może się zmienić przed stabilnym wydaniem.

01

Tokenizer BETA

Tokenizer znakowy z tokenami <PAD>, <UNK>, <BOS> i <EOS>.

Tokenizer(text).encode("Ala ma")
02

Warstwy tensorowe BETA

Embeddingi, pozycje, Linear, LayerNorm, FeedForward oraz causal self-attention.

Embedding · PositionalEncoding · LayerNorm
03

Bloki Transformera BETA

Multi-head attention, połączenia rezydualne i kilka bloków do budowania modelu językowego.

MultiHeadAttention · TransformerBlock
04

TransformerLM BETA

Trening następnego tokena, AdamW, CrossEntropyLoss, clipping gradientów, checkpointy i generowanie.

model.train_text(text); model.generate(prompt)
transformer_beta.py BETA
from tota import Tokenizer, TransformerLM

tekst = open("data.txt", encoding="utf-8").read()
tokenizer = Tokenizer(tekst)
model = TransformerLM(tokenizer, dlugosc_sekwencji=32, rozmiar_embeddingu=64)
model.train_text(tekst, epochs=5)
print(model.generate("Ala ma", max_tokens=20, top_k=5))

BETA: Transformer jest przeznaczony do nauki na małych zbiorach tekstu. Nie jest jeszcze produkcyjnym LLM-em i wymaga dalszych testów oraz optymalizacji.
