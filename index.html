01 — idea

Neuronowe podstawy,
bez czarnej skrzynki.

tota pomaga zobaczyć, jak dane przechodzą przez neurony, warstwy i funkcje aktywacji. Kod jest niewielki, czytelny i dobry do nauki podstaw uczenia maszynowego.

Python 3.9+prosty interfejs
PyTorch ≥ 2.0obliczenia tensorowe
CPUlekki start bez GPU

02 — quickstart

Pierwsza sieć
w kilku linijkach.

01 / 03
example.py
from tota import Layer, Network

training_data = [
    ([1], 0), ([2], 0),
    ([6], 1), ([8], 1),
]

network = Network([
    Layer(5, 1),
    Layer(1, 5),
])

print(network.learn(training_data, 0.01, 5000))
print(network.predict([7]))  # 1

03 — instrukcja

Od pustego pliku
do pierwszej predykcji.

01Przygotuj dane+

Każdy przykład to para: wektor wejściowy i oczekiwany cel. Dla klasyfikacji używaj zwykle celu 0 albo 1.

dane = [
    ([1, 2], 0),
    ([6, 7], 1),
]
02Zaprojektuj warstwy+

Drugi argument Layer musi odpowiadać liczbie wartości z poprzedniej warstwy.

Network([
    Layer(8, 2),
    Layer(1, 8),
])
03Uruchom uczenie+

Małe learning_rate uczy wolniej, ale stabilniej. Zacznij od 0.01.

network.learn(
    dane, 0.01, 5000,
    show_progress=False,
)
04Sprawdź wynik+

predict zwraca klasę 0/1. Zawsze sprawdź kilka przykładów po treningu.

for x, cel in dane:
    print(cel, network.predict(x))

04 — API

Trzy klocki
do budowania sieci.

01

Neuron

Pojedynczy neuron z wagami, biasem i wybraną funkcją aktywacji.

Neuron(weight, bias, activation)
  • forward(x) — oblicza wynik
  • learn(...) — uczy neuron
  • activation_derivative() — pochodna
02

Layer

Warstwa wielu neuronów, która przyjmuje wektor wejściowy.

Layer(ilość_neuronów, ilość_wejść)
  • forward(x) — przejście w przód
  • obsługuje aktywacje
  • tworzy losowe wagi
03

Network

Łączy warstwy i udostępnia uczenie oraz predykcję.

Network([layer, ...])
  • learn(...) — SGD + backprop
  • predict(x) — klasyfikacja 0/1
  • predict_ReLU(x) — wynik ReLU
